## What changed

This is frontend only, with no API, schema or dependency change.

| File | Change |
|---|---|
| `apps/web/src/components/data-health/model.ts` | `sourceState(source, latestGapEnds \| undefined, now)`. `undefined` means the host call is loading or has failed. Partial and Healthy, the states only the gap summary can clear of Overdue, return the new **`unknown`** state. `attentionCount` returns `{ count, atLeast }`, where `atLeast` means the summary is missing and a source it could make Overdue is still left. |
| `model.test.ts` | One case per source state with the host missing (blocked, disabled, running, failing, skipped and never run stay; partial and healthy read unknown), the would-be-Overdue source, and the floor count (`atLeast`) with and without uncertain sources. |
| `atoms.tsx` | `sourceStates.unknown`: label "Unknown", `CircleHelp` icon, muted tone (dashed border, like Never run), and the hint "Missed runs come from the collector host's gap check, which didn't load, so this source may be overdue. Retry on the Collector host card." |
| `sources-table.tsx` | The call site passes `host.data?.latest_gap_ends` with no `?? {}` default. While the host call is pending, an Unknown row shows a pill-sized skeleton and no note. After a failure, the row shows the Unknown pill with the status note "Gap check didn't load". The panel note hides its count while the host is pending, then reads "at least N needs/need attention" when the count is a floor. The singular is now correct ("1 needs"). |
| `nav-badge.tsx` | Hidden while either call loads. After a host failure the badge reads "N+", announced as ", at least N source(s) need(s) attention". |
| `run-drawer.tsx` | One line: the drawer pill uses the same undefined-aware call. Without it the drawer kept the bug (Healthy) for the same source. This file is outside the brief's ownership list; it is the third caller aud-014 names. |
| `docs/DECISIONS.md` | DEC-196. |

Unchanged:
- the precedence of Blocked, Disabled, Running, Failing, Overdue, Skipped and Never run (DEC-096, DEC-123);
- every state while host data exists, including stale data after a failed refetch, which still counts as known;
- the host card's error and Retry.
