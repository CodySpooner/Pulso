## Change

The Data Health API-down error (`h2` "Can't reach the API") rendered through `PanelError`, which hard-coded `EmptyState size="sm"`, so its title was `text-body font-medium`. That is smaller than the panel `h2`s it stands in for (`text-title-3 font-semibold`).

- `atoms.tsx`: `PanelError` takes `size?: "sm" | "md"` (default `"sm"`) and passes it to `EmptyState`. The existing `size` option is the current component pattern for this; no new token, class or component.
- `data-health.tsx`: the API-down error passes `size="md"`.
- Inline panel errors pass no `size`, so they keep `"sm"` (body, 500) and their `h3`. Heading levels are unchanged.
- imp-062 edits the Error ID line inside `PanelError`'s body. This change touches only the signature and the `size` line, so the two stay compatible.

`size="md"` also brings the `md` side padding (`px-6`, 24 px, was `px-4`, 16 px). The `py-12` override is kept. The body copy still wraps to 2 lines at both widths. Clicks to recover from API down: **1** (Retry), unchanged.

DEC-180 was not used: the change reuses an existing option and needs no decision.
