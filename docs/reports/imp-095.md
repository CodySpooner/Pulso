## Reproduction (imp-092 leftover finding, P3)
The finding is **confirmed** on `main` (`973ad0a`). In `PreviewResult`, the Import button stays focusable while it is locked (`aria-disabled`): while an import runs ("Importing…"), and when the source blocks it ("No import adapter yet"). The shared Button's `aria-disabled:opacity-50` fades the whole control, its `:focus-visible` outline included.

**Method:** fixtures, E2E auth bypass, and a commit route held pending. A keyboard user chooses `rates.csv` and presses Enter on **Import 3 rows**. The new spec then screenshots the focused **Importing…** button and measures each side of its ring against the card. The ring's pixel is the strongest one between the button and 8px out on that side.

| Theme | Ring token on card (full) | `main`, measured (all 4 sides) | This branch, measured (all 4 sides) |
|---|---|---|---|
| Light | 3.96:1 | **1.95:1** (below 3:1) | 3.96:1 |
| Dark | 11.25:1 | 3.61:1 (faded to a third) | 11.25:1 |

The values are the same at 1440px and 375px, and the same for the blocked button in light (1.95:1 → 3.96:1). Baseline screenshots are `docs/screenshots/imp-095/before-{importing,blocked}-1440-{dark,light}.png`.

## The fix
`apps/web/src/components/data-health/import-panel.tsx` (+2 / −1), on the `PreviewResult` Import button's `className` only:
- **Added:** `aria-disabled:border-border aria-disabled:bg-secondary aria-disabled:text-subtle-foreground aria-disabled:opacity-100`.
- `tailwind-merge` drops the Button's `aria-disabled:opacity-50` in favour of `opacity-100`. The aria variants come after `hover:` in Tailwind v4, so the primary hover fill doesn't come back on a locked button.
- **Locked look:** a quiet secondary control. The label is 4.98:1 in light and 5.29:1 in dark (disabled text is exempt, but it still passes AA), and the 1px border keeps the box size.
- **Ring:** full token strength.
- **Unchanged:** the action guard (`!unavailable && onImport()`), `aria-disabled`, `aria-describedby`, the label text, the live regions, `useTakeLostFocus` and the shared Button.
