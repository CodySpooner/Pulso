## Change

Code changes are in three files:

- `apps/web/src/components/data-health/run-drawer.tsx`: the four fixes below.
- `apps/web/src/components/data-health/model.ts`: the type-label map moved here and is exported as `typeLabel`.
- `apps/web/src/components/data-health/sources-table.tsx`: deletes its local map and imports `typeLabel` from `./model`. Nothing else in the file changed, so imp-152's StatusNote line is untouched.

The four fixes:

- **imp-119: Retry after.** The fact label "Retry not before" now reads "Retry after", like the row and the re-enable dialog.
- **imp-127: no raw values.**
  - Type reads `typeLabel[source.type]`, so the table and the drawer share one map.
  - Status reads the pill's label (`sourceStates[state].label`), then the switch once: "Enabled", or "Disabled" plus a muted "since <UTC date>" when `disabled_at` is set. When the pill itself is Disabled, the pill's word is dropped, so FX reads "Disabled" and never "Disabled · Disabled".
  - "since" now shows only while the source is disabled. Before, a stale `disabled_at` could have shown on an enabled source.
  - The Key fact is unchanged: raw key, mono.
- **imp-128: never-run empty state.** The title is still "No runs yet". The body gives why, then next:
  - Why: "Runs appear here once the collector host runs this source." for an enabled source, or "This source is disabled, so the collector host won't run it until it's enabled." for a disabled one.
  - Next, only for actions that source has now:
    - "Press Run now in the Sources panel…" only when Run now could run. That uses the same three conditions as the table's `runBlocker`: `live_runs_allowed`, enabled and online.
    - "…import a CSV from the CSV import panel…" only when `csv_import === "ready"`. A preview-only template checks files but adds no run, so it isn't suggested.
    - When both apply, they are joined in one sentence.
  - The per-source import entry stays with imp-052.
- **imp-131: targets table on a phone.**
  - The target cell is `w-full max-w-0 truncate`. It takes whatever width Status and Payload leave and truncates inside it, so the table never overflows at any width. The full target is still in the cell's `title`, as before.
  - The header row is `whitespace-nowrap`, and "Raw payload" is now "Payload". The cell's hover still says "Raw payload id…".
  - The region keeps `role="region"`, its label and `tabIndex={0}` (keyboard scrolling). No row animates.
  - imp-069's `ScrollCue` was **not** reused. The table now fits, so there is nothing to cue. The cue is also a private function in `coverage.tsx`, which this brief keeps off-limits (imp-152).
