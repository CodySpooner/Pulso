## Template (`csv-v1`)

`asin,title,category,rank,rank_kind,price,currency,rating,review_count,gtins,observed_for`. Required: `asin` (10 uppercase letters or digits), `title`, `category`, `rank` (≥ 1). `rank_kind` is `bsr` (default) or `movers`; `currency` defaults to `USD`; `rating` 0–5 with up to two decimals; `review_count` cumulative; `gtins` one or more UPC/EAN/GTIN codes; `observed_for` blank = the import day. Help text (in `docs/DATA_SOURCES.md` § Amazon and the vault note): obtain the data lawfully. CSV is not an exemption from Amazon's terms. Downloads stay header-only (DEC-191), so the help text lives in the docs rather than in the file.
