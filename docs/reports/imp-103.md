## Root causes

- **F-11a:** `app.add_defaults(configuration)` is lazy, so the first `app.conf` read calls `configuration()` and fixes the result for the process. `import_default_modules()` reads `app.conf.imports`. The plan fixture had just patched `celery_app.get_settings` to the sources `settings` fixture (`redis://localhost:6379/0`), so the broker was pinned to `/0` before `apps/workers/tests/conftest.py` could set `/15`. Importing the configured list directly loads the same modules (`tasks`, `ops`, `registration`) from the same `imports` setting and leaves `app.conf` unread.
- **F-11b:** `live.py` computes `exhausted_until` from `datetime.now(UTC)`, and the test then recomputed the deadline from a second `datetime.now(UTC)`. A month end between the two reads gives the next month's deadline on one side only. Patching `lifecycle` too keeps the second `collect` deferred by the same clock: `retry_not_before − now` is above the 600 s retry-wait cap in both cases, so nothing sleeps.
