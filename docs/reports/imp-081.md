## What changed
- **Row action.** Every source row (desktop table and phone card) has a ghost action next to Run now. Its label comes from `SourceHealth.csv_import`:
  - **Import CSV** when the source is `ready`.
  - **Check CSV** when it is `preview_only`. A hint explains: "No import adapter yet: check a file against the <source> template now."
  - **Import CSV**, `aria-disabled`, when there is no template. The hint says "No CSV template for <source> yet."

  Hints use the shared tooltip, so they also show on keyboard focus. `model.ts` `importEntry` holds the mapping.
- **Where it lands.** The action selects that source in the existing panel: same select, same template link, preview and commit endpoints. It focuses **Choose CSV…** and scrolls it into view (instantly under reduced motion). Picking a template sends no request.
- **Pending work is never lost silently.** If a file is open for another source, the row does not switch. The panel asks: "<file> is still open for <source>. Switching checks it against <target> instead." **Switch to <target>** is focused and described by that line, and it does what the Source select does.
  - While an import is running, the line reads "<file> is importing into <source>. Choose <target> once it finishes." The line takes focus, and there is no Switch.
  - The question lapses with its file: once it is imported or replaced.
  - DEC-145 still moves focus to Open runs after the import.
  - A file over 20 MB was never sent, so the row switches at once.

## styleseed-design-review: 97/100 (A), after 1 fix round on the rebased tree
I re-reviewed the refreshed screenshots and the merged code after the rebase.

**Fix round 1 (focus ring, AA):** the unavailable row action (no template) used the shared Button's `aria-disabled:opacity-50`. imp-089 and imp-095 showed that this also fades the focus outline, to 1.95:1 on white. A focus indicator needs 3:1.
- Dimming the text with `--subtle-foreground` (the panel's approach) was tried and rejected. On a ghost button it is barely lighter than the default muted text, in both themes, so the unavailable action stopped reading as unavailable.
- Instead, the button keeps `opacity: 1` and only its icon and label fade (`aria-disabled:*:opacity-50`, label wrapped in a `<span>`). The ring is at full token strength: 3.96:1 light and 11.25:1 dark, the token values imp-089 and imp-095 measured. The look is unchanged.
- `import-entry.spec.ts` now asserts the button's opacity is 1 and the label's is 0.5. The assertion failed (0.5) before the fix.
