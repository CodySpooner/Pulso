## What was built

- **API:** `GET /v1/products/{id}/sellers` (operationId `get_product_sellers`) in a new router, `apps/api/src/pulso_api/routers/product_sellers.py`, registered in `main.py`. It is workspace-scoped through `current_principal` and reads existing tables only. It returns `rows, next_cursor, spread {min, p25, median, mean, p75, max, n, missing, untrackable, points, as_of}, band {low, high, reason}, counts {active, delisted_30d, new_14d, as_of}, series_90d, crawler {status, since, reason}, as_of`. Rows are cursor-paginated (1–200, default 100).
  - **Delisted** only when a complete crawl omitted the listing. "Complete" is the store's own `shopify_catalog` target reaching `success`, the per-store unit of `collector_runs.complete`, and the only path that writes `delisted_at`. A partial or failed last crawl, a blocked or untrackable store, or no crawl at all reads `unknown`, with the reason.
  - **Spread:** active, trackable stores only, one price per store, at the `fx_rates` rate for each snapshot's UTC date (`rate_as_of`, half-even). No rate means the seller is left out and counted in `missing`; untrackable stores are counted in `untrackable`.
  - **`new_14d` uses the stable panel.** It wasn't defined for sellers, so DEC-247 (g) sets the default: the store has been in Pulso for at least 28 days and the listing started in the last 14.
  - **`series_90d`:** a day counts only if a store catalog crawl succeeded on it; every other day is a gap with a null value.
  - **Crawler state** comes from the `shopify_stores` source row. **Band** is always `{null, null, "needs_landed_cost"}`. **Running ads** is always `NoSource`.
  - A merged id answers 308 to the survivor's sellers.
- **Web:** `apps/web/src/app/(app)/products/[id]/sellers/` holds `sellers-tab.tsx`, `summary.tsx` and `model.ts` (pure helpers). The shell change in `product-page.tsx` is 3 lines: the import, and a sellers branch beside p2-07's overview branch inside the rail grid.
  - **Summary strip:** a spread card with an inline-SVG strip plot (median tick, "Middle 50%" shading, a dot per seller with the store on hover); a sellers card with active / new in 14 d / delisted in 30 d and a 90-day SVG sparkline whose gaps break the line over a dashed floor; and a band card in a designed "no source yet" state.
  - **Filter chips** Active only / Include delisted / New in 14 d / Tracked only are kept in `?sellers=`; `F` cycles them.
  - **Dense table:** sticky header, tabular right-aligned numbers, a freshness dot and source on hover per row, the price's provenance card. Started says store date or first seen. Unknown explains itself on hover, focus and tap. Running ads reads "No source yet".
  - A **crawler banner** shows whenever the crawler isn't enabled. Below 768 px sellers are **cards**, with delisted ones in a collapsed **Delisted (n)** group. Rows never animate.
