## Chosen rules (DEC-267)

- **File:** Google's download imports unchanged. The filters' Country, Category and Time period fill every row; a monthly or custom period fails the file ("Download the weekly report"). A file without those lines needs `report_week` and `country` columns. Renamed headers go through the source's saved `csv_mapping`; an unknown header fails closed.
- **Rows:** `observed_for` = the Monday that starts the report week (a `report_week` that isn't a Monday is a row error). Unique on `(source_id, country, category, observed_for, rank, raw_payload_id, parser_version)`, NULLS NOT DISTINCT. The same file twice skips before parsing; a re-parse by the same parser inserts nothing. 1,000 rows per statement, because a weekly file holds about 16,000. A trigger rejects UPDATE and DELETE.
- **Money:** `price_min_minor` / `price_max_minor` plus `currency`; a price without a currency is no price, never USD by assumption.
- **Products:** GTINs are stored as Google wrote them. `link_products()` normalises both sides with M-4's `gtin14`, follows merges with `canonical()`, and links a row only when its valid GTINs reach exactly one live product. It writes no `match_candidates` or `match_decisions` (no listing moves).
- **Weekly change** (for the surface): the owner's download has no previous rank, so the change comes from the previous week's import of the same country and category, matched on title and brand; absent last week reads "new", never 0.
- **Flag:** the source row stays disabled; CSV import works on a disabled source, like every CSV fallback.
