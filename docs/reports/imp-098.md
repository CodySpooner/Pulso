## Change

All of it is in `apps/web/src/components/data-health/run-drawer.tsx`. There is no new component or formatter, and the fix reuses the inline `toLocaleString("en-US")` that `sources-table.tsx` and `import-panel.tsx` already use.

- **Facts wrap.** The shared `Fact` `dd` changed from `truncate` to `wrap-break-word`. A value wraps at spaces, and a single token breaks only if it can't fit on a line by itself. The source facts and the run facts both route through `Fact`, so this one class change covers every fact.
- **Clean breaks.**
  - In Rows, non-breaking spaces keep each count with its unit (`1,092 unchanged`). Lines break only after a "·", so a line never starts with one.
  - In Status, the "since" timestamp is `whitespace-nowrap`, so it is never split as "09:00 / UTC".
- **Counts grouped:**
  - Quota (`2,650 / 50,000`)
  - Rows (fetched, inserted, updated, unchanged)
  - Targets (`n of m succeeded`)
  - Requests
  - Seed list "approved targets"

  HTTP status codes and ids are not counts, so they stay ungrouped.
- **Key** stays `font-mono` and unbroken: it has no spaces, and source keys are short.
