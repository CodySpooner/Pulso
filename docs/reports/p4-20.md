## Behaviour (DEC-331)

- **Score.** `opportunity(trend, saturation, margin)`:
  - The components are `trend` (momentum, 0.40), `margin` (0.30), `saturation` (room, 0.20) and `risk` (safety, 0.10, always missing).
  - Each input's `z` is its 0–100 value, so its `contribution` is its points, and `explain()` renormalises.
  - Opportunity = round(O, 1), as of the oldest present input.
  - Version `000-de3f6e76320d`. Nothing is written to `scores`.
- **Momentum** is always Trend (Beta), because no forecasts table exists yet.
- **Margin**, from the caller's `workspace_product_economics` row (the row behind Discover's and the Overview's best margin):
  - A complete row gives its `margin_bps`.
  - When `duty_not_set` is the only gap, the margin is `landed_cost()` of the row's USD lines (price, goods at q = 1, freight, customs) plus the workspace's fee and returns settings, at duty 0. It's the one function; there is no second formula.
  - Any other gap leaves the margin missing with its source ("insufficient signal"). No settings row means `source: null` ("no source yet").
  - R-16 stays as it is for Discover, Profit and the Overview.
- **Floor.** m_ref is the config value `floor_bps` = 3000; no settings column exists. With m < m_ref, the value is min(O, 25), a `margin_floor` penalty records the points cut, and `reason` reads "margin below your floor".
- **Duty not set.** `cautions: ["duty_not_set"]`, and `confidence` = coverage − 0.2. Freshness isn't built, so coverage stands in.
- **Endpoint.** `range` = 7d, 30d, 90d or all (default 90d); `cursor`; `limit` 1–100 (default 90).
  - `latest.{trend,saturation,lifecycle}` is each kind's newest row, a NULL row keeping `explanation.reason`. No row gives `{value: null, reason: "No source yet: nothing has scored this product."}`.
  - `history` holds those kinds in the range, newest day first, then the newest id, with a keyset cursor `[day, id]`.
  - `opportunity` is computed for the principal's workspace.
  - An unknown product is 404; a merged one is a 308 to the survivor, with the query kept.
