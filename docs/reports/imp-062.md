## What changed

- `apps/web/src/components/pulso/copy-button.tsx`: new `SelectableId`, the ID shown beside a CopyButton. It is a `tabIndex=0` span; keyboard focus selects the whole ID (`selectAllChildren`). It keeps `select-all`, so pointer and manual selection are unchanged. Screen readers get `role="textbox"`, `aria-readonly` and `aria-label`. Focus shows the global `--ring` outline, and `hit-area` gives a 44 px coarse-pointer target.
- ErrorState, PanelError and the not-authorized user ID use it in place of their `select-all` spans. The look is the same, except for a focus ring on keyboard focus. The not-authorized ID keeps `[data-mono]` (the old `<code>` styles). No new information is shown.
- Copy, its feedback (Copied, Couldn't copy, the hint, the live region, Esc) and the 5 s timing are unchanged.

## Flow and counts

| Display | From a failed "Copy error ID" | Pointer |
|---|---|---|
| ErrorState (page / inline) | Shift+Tab ×2 (past Retry), then Ctrl/⌘+C: 3 keystrokes | 1 click + Ctrl/⌘+C (unchanged) |
| PanelError (Data Health) | Shift+Tab ×2, then Ctrl/⌘+C: 3 keystrokes | 1 click + Ctrl/⌘+C (unchanged) |
| not-authorized | Shift+Tab ×1, then Ctrl/⌘+C: 2 keystrokes (the ID sits right before Copy) | 1 click + Ctrl/⌘+C (unchanged) |

Tab order follows the visual order (the ID sits above the buttons), per vault Design/Accessibility. When the clipboard API is denied or missing, the browser's own copy still works.

## Limits

- The not-authorized ID renders only for a real Clerk session. Playwright covers the shared component through ErrorState and PanelError, and the real page waits on imp-064 (owner Clerk dev keys).
- A non-editable ARIA textbox has no caret, so arrow keys don't move through the ID and Ctrl+A selects the page. The ID is already selected on focus.
- In not-authorized, `truncate` clips the coarse-pointer hit area to the ID's own box. That box is the same tap target as before.
- On the screen-reader browse path, "Error ID" is read twice (the visible label, then the textbox name).
- imp-077's CSV import error line (`import-panel.tsx`) still shows its ID in a plain `select-all` span. Pointer users can select it in one click, but it isn't keyboard-focusable. That panel is outside imp-062's target list, so it is left unchanged here (backlog row 3).
