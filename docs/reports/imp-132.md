## What changed

- `atoms.tsx`: new `StaleLine`, built from PanelError's parts (Retry, `SelectableId`, `CopyButton`, the same API-down copy, now one `API_DOWN` constant) in the import panel's error-line layout. The icon sits inline like imp-123's action error. It is `role="group"` named by what failed, so Retry is announced with its context. It is a warning-tinted strip under a panel header, or `boxed` on the page and in the drawer.
- `api.ts`: `useCoreDown()`, true when both core calls (`/sources`, `/host`) failed. It decides the page line and keeps the panels from repeating it.
- `data-health.tsx`, `sources-table.tsx`, `coverage.tsx`, `summary-cards.tsx`, `run-drawer.tsx`, `import-panel.tsx`: the 10 branches above, and the line where its request's panel is. Only the `isError`/data branches and the new line changed. imp-124+125's name cell and drawer header are untouched.
- DEC-197 (proposed): one line per failed request; the drawer always shows its own line; warning tint; no announcement (imp-135 owns that).

Copy (what, how old, why): "**Couldn't refresh sources.** Showing data as of Oct 22, 14:00 UTC. The API is restarting. Try again." · Error ID · Retry · Copy error ID. When the API doesn't answer: "**Couldn't refresh Data Health.** Showing data as of Oct 22, 14:00 UTC. The Pulso API didn't answer. When it runs on your PC, this also means the PC is off." · Retry.
