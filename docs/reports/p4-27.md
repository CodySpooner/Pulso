## Behaviour

- **Rules tab** (`/alerts?view=rules`, beside Inbox and Archived):
  - Columns: Rule (with the status line under it), Type with the threshold, Target (the product linked to its Suppliers tab), Last fired, and Notifies (switch plus Off, On or "Muted until …").
  - Status lines: "No source yet", "1 evaluation skipped: data gap Oct 19 → Oct 21", "Evaluated 8h ago" or "Not evaluated yet".
  - Testing defaults carry a Default tag, with Edit and Mute but no Delete.
  - Phone: stacked cards. The name, type and target take the full width, and the switch and actions share the last row.
- **Mute:** 24 hours, 7 days, or until unmuted (`9999-01-01T00:00:00Z`; the API's null means unmuted). Unmute sends null.
- **Builder:**
  - The sentence: When [any supplier / one offer] [changes price by / changes freight by / goes out of stock / comes back in stock] [N] % → notify In-app. Discord and Email are disabled "Phase 7" chips.
  - The name defaults to "<product>: <type> ±N%".
  - The API's 422 messages show beside the % or name field.
  - Edit fixes type and target.
  - Escape and Cancel return focus to the opener.
- **Create alert, 2 clicks:** Product Page header Create alert (1), then Create rule (2). The status line then names the rule with a View rules link.
