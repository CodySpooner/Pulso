## Cause

- While `duty_default_bps` is NULL, every supplier listing's row is incomplete (`duty_not_set`), so every `cost.margin_minor` is NULL.
- The view's pick (0010 + 0014) orders by `… cost.margin_minor DESC NULLS LAST, cardinality(cost.missing), l.id`, so `l.id` decides. `calculate()`'s fallback had the same rule: the fewest missing inputs, then the lowest id.
- `margin_of()` re-costs that row at duty 0 (DEC-331 b), so Opportunity scored whichever listing was created first.
