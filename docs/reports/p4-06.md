  Left at 96: the empty state has no action (on a static page there's nothing to send the owner to), and the raw `model_version` label is deliberate (it's what a row stores).

  - Loading: `loading.tsx` skeleton, during client navigation.
  - Empty: "No score is built yet" (vitest).
  - Error: the (app) error boundary. The data is a build-time import, so tsc and the drift test catch a bad file before it ships.
