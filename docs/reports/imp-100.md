## Finding reproduced

On `8a4575f`, `template_csv` wrote a header plus one example row of valid values, so every download parsed as one valid row. New tests run against the old `templates.py` failed in **12 places**. The ones that matter most:

- The real FX adapter committed the downloaded FX template as `success`, 1 row, which is the `2026-01-01 USD/JPY 150 manual` rate.
- The registered real Trends adapter committed the downloaded Trends template as `success`, 1 row ("example keyword").
- Through the service, all 4 templates committed `success`, 1 row each (fake adapter).
- The API commit route accepted the downloaded Trends and FX templates.
- All 4 downloads carried a data row (service and API).
