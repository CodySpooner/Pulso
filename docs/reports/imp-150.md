## Notes for the lead

- **Status:** a failed upsert gives a `partial` run, not `failed`, with `error_code` `ValueError`. That is the framework's existing outcome whenever an adapter's upsert raises after the capture is stored (`execute_run`: the target becomes `partial` when a `raw_payload_id` exists). No rows are written. I left it unchanged; the existing import tests also accept `failed` or `partial`.
- **Nothing sets `ListingVariant.delisted_at` yet.** The live catalog delists listings only (`shopify_stores/__init__.py` finalize). So the variant filter is defensive today, matching `records.py`'s `whole` check, and test 2 sets the column directly.
