### `run_id`: dropped, not allowlisted

`collect_run` (`tasks.py:168`) wraps its whole body in `job_id.set(str(run_id))`, and the `collection_failed` call sits inside that block. So the formatter already prints the same id as `job_id` on that line, and on every other line in the run. Allowlisting `run_id` would only print it twice and add a key that no other call site uses. Dropping it keeps the allowlist down to keys that carry something new.
