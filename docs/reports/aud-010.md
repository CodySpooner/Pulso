## Result

**10 findings: 4 P2 and 6 P3.** Every one is new to [[Improvement Backlog]] and `docs/BACKLOG.md`. 9 more observations are already queued and are listed under Duplicates.

The happy paths are short. Data Health is one click from five places, the error behind a blocked source is one click from its row, a CSV import takes two actions, and a dead API recovers with one Retry. The friction is off the happy path:

- the reason behind a state (Overdue, the retry deadline) is missing or hidden;
- three failure paths give no visible feedback (a failed toggle, a failed Run now on a phone, an unavailable Run now tapped on a phone);
- three drawer and import surfaces show copy that contradicts the page or drops information.

## Method

- **Fixtures only.** `mockAdminApi` from `apps/web/e2e/data-health/fixtures.ts` answers every `/api/v1/admin/*` call. The page clock is pinned to 2026-10-22 14:00 UTC.
  - Shopify is blocked (5 × 429, retry not before 15:00 UTC).
  - CJ is healthy.
  - Google Trends is Overdue (open host-offline gaps at 10:00 and 11:00 UTC).
  - Frankfurter FX is disabled, never run, and `csv_import: ready`.
  - The host heartbeat is 4 min old.
- **Environment.** `next dev` with the E2E auth bypass, reduced motion, Chromium 1440×900 and 375×812, plus a `hasTouch` context for the phone taps. No live source, collector stack, Clerk session, secret or env file was involved.
- **Walk script.** A scratch Playwright spec and config outside the repo (not committed, as in imp-074). It counts each click, tap and key, and records on-screen text, geometry, the accessibility tree and API calls to JSONL. The repo config's port 3100 was held by another process (PID 4420), so the scratch config only moves the dev server to ports 3813 and 3814.
- **Counting rules.** A click is one pointer press on an app control. A file pick in the OS dialog counts separately. Typing a reason counts as "+ typing". Keys are listed as pressed.
