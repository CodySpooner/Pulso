## UI bar

**styleseed-design-review** (index, board, cards, toast and toggle):
- First pass: **91 (A)**. The deductions:
  - −6 colour: a selected table row put subtle text at **4.45:1** on `bg-brand-muted` in dark. The new AA e2e check found it.
  - −2 writing: "card" and "product" for the same thing.
  - −1 motion: a hard-coded easing curve.
- One fix round: the row now uses `bg-selected` with the Matching queue's brand inset bar; the copy says "product" throughout; the shift uses `ease.standard` and `duration.base`. That gives **98**.
- Also fixed from the screenshots:
  - index tiles go to 4 columns from 1280 px;
  - only the count is mono in "5 products";
  - note text is muted, so the product name leads;
  - the table note is one line tall and the row centres;
  - under 480 px a card lies on its side and index covers are 2:1, so a phone shows about twice as much;
  - the checkbox sits above its label's hit area.
- Left: the inline title editor's "Enter to save · Esc to cancel" hint pushes the lines below it down by one line (backlog row 8).

**States, for each view:**
- Loading: skeleton tiles, or the header plus card skeletons.
- Empty:
  - no boards: the name field is already open in the empty state;
  - no archived boards: "Show active boards";
  - an empty board: "Browse Discover", saying the Add to board button comes in a later Phase 4 update.
- Error: `PanelError` with the cause, the error ID and Retry, for the lists and for the cards.
- Stale: `StaleLine` with the as-of time over the kept cards.
- No source yet: "No image yet" on a product without an image. Card stats come with imp-454.
- Also designed: "Board not found", and the archived banner.

**Keyboard and motion:**
- Every control is reachable by Tab: checkbox, reorder handle, product link, note, … menu, header edit buttons, the toggles, the selection bar.
- The handle and checkbox fade in on focus and hover, and always show on a coarse pointer and when selected. The e2e checks opacity 1 and a solid ring on the focused handle.
- Radix menus handle the arrows, Enter and Escape. dnd-kit announces each move.
- Reduced motion:
  - the global clamp stops the sortable shift;
  - the drag lift is `motion-safe` and the tile hover lift is `motion-reduce:translate-y-0`;
  - toasts and the selection bar are Motion components under the shell's `MotionConfig reducedMotion="user"`.
- Nothing is virtualized.

**Contrast and tokens:**
- Tokens only; the hex colours are in the e2e fixture SVGs only.
- An e2e check runs the p2-39 `contrastMisses` helper over `#main` in dark and light: the index, the grid with a failed note and a selection, and the table with a selected row. No misses.
- Status never relies on colour alone: a selection shows a ticked checkbox and a brand ring or inset bar, and a failed note shows words and a Retry button.

**375 px:** e2e `phone width` finds no horizontal page scroll on the index, the grid or the table. The table scrolls inside its own box.

**Clicks (main flow): create a board and add a note**
- **Create a board: 1 click.**
  - New board, type the name, Enter. Mouse only: 2 clicks (New board, Create board).
  - On a first visit (no boards) the field is already open: 0 clicks, type, Enter.
  - The new tile has focus, so Enter opens it (or 1 click).
- **Add a note: 1 click.** Click the card's note field and type; it saves itself.
- **Total: 2 clicks plus two Enters** (4 clicks mouse only), on a board that already has a product. Putting a product on a new board needs the Add-to-board popover and `B` (imp-455); this UI has no add path yet.

**Other flows:**
- Reorder: one drag, or 2 clicks (…, Move up), or keys only.
- Send to Testing: one click per checkbox (or one plus Shift-click for a range), then 1.
- Archive: 1 click; Undo is 1.
