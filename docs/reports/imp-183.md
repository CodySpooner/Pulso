## Root cause (imp-183)

`press-and-exit.spec.ts:10` clicked Cancel inside `page.evaluate`, then polled each animation frame for `[role=dialog][data-state=closed]`. The closed state only exists while the 120 ms exit runs. Sometimes a long task falls between the close and the next frame. Then the exit finishes at that frame, Radix unmounts the content before the frame's rAF callbacks run, and the poll never finds it. The loop has no bound, so the test hangs until the 60 s test timeout.

**Reproduced** with a temporary demo spec (deleted): a MutationObserver busy-waits 300 ms as soon as the dialog reports closed. Today's poll then **hung in 3 of 10 runs** (the first try, then 2 of 8 with `--repeat-each 8`). That matches the lead's runs: it failed at 19:45Z, then failed on both tries at 20:15Z, and it passed alone.

## Change

Web and tests only. No API, schema, dependency, CI or copy change. Tokens only. Only `opacity` and `transform` are keyed by this change. The reduced-motion layers are untouched.
