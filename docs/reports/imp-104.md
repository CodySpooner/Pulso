## What changed

`packages/sources/src/pulso_sources/imports/__init__.py`, in `_active_run`, the one function both callers (`commit_import`'s retry and `replay_import`) go through, while they hold the source row `FOR UPDATE`:

1. One conditional `UPDATE` first ends every queued/running import run (`trigger = 'csv'`) on this capture whose age reaches the threshold. It writes the end fields `recover_source` already writes: `status failed`, `complete false`, `finished_at` now, and `abandoned` as `error_code` and `error_message`. No other column or row changes.
2. The existing lookup then finds no active claim, so the caller's existing path runs: it claims the capture, commits (the abandonment commits in the same transaction, under the lock), and re-runs the stored capture. No second capture, no new S3 PUT.
3. A younger claim is untouched and still returns `skipped` / `reason: in_progress` with its run id.

**Threshold:** DEC-098's rule, the greater of 2 h or twice the run's budget, from `started_at`, or `queued_at` if it never started. Imports run on `execute_run`'s default budget (`COLLECTOR_WALL_TIME_SECONDS`, 45 min), so it is 2 h by default. The rule is reused rather than imported, because `stale_after` lives in `pulso_workers`. No `.env.example` change.

**Scope guard:** only import runs (`trigger = 'csv'`) can be abandoned here. A replay of a collector capture never ends a scheduled or catch-up run from the API; `recover_source` stays the only path for those.

**Status vocabulary:** the brief's "status abandoned" is recorded the way the framework records it, `failed` + `error_code = "abandoned"` (DEC-098). A literal `abandoned` status is unknown to the API's and the web's status types.

**Known ceiling (DEC-221):** recovery first checks that the execution lock is free; the API has no such liveness check for an import. An import still executing more than 2 h after it started could finish after it was abandoned and overwrite its own end fields. Its observations dedupe on `(entity_id, raw_payload_id)`, so each row is written once.
