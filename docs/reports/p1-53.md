## Failures and root causes

All three were reproduced and fixed in `mcr.microsoft.com/playwright:v1.64.1-noble`, the version pinned in `apps/web/package.json`. Chromium on Linux sets text about 2 % wider than on Windows. That applies to every column of the Sources table.

### 1, 2. "Overdue names its missed slot … at 1440px dark / light" (line 43: 32 px, expected 16)

- **The wrap:** imp-124 put the note in a fixed 180 px box (`md:w-45`). The slot "Missed Oct 22, 10:00–12:00 UTC" measures **180.0 px** on Windows, so it fit by 0 px, and **184.5 px** on Linux. So it wrapped after the en dash.
- **Hidden behind it:** the same test's next check (`the table still fits`) also fails on Linux. The 1440 table's min-content is **1,154.8 px** in a **1,140 px** region even with the slot wrapped (Windows: 1,132.9 px), so the region overflowed by 15 px. With the slot on one line it overflows by 19 px. With Freshness also on one line (imp-148) it overflows by 40 px.
- **The assertion is correct.** 16 px is the `text-label` line height, which doesn't depend on the font. It failed because the text really wrapped.

### 3. "first load keeps the layout stable at 375px light" (CLS 0.157, limit < 0.1)

The shifts were captured with `PerformanceObserver` sources (node, previous and current rect) in the container:
- **Steady part (0.024 / 0.025):** at 375 px the loaded host card is **36 px** taller than its 5-bar skeleton: Run now's "Off here: …" and the Open gaps line each wrap to two lines. The backups card is **14 px** taller: the run strip's count wraps beside its cells. Everything below moves 36–50 px when the data lands.
- **The jump (0.151–0.157):** when Backups (or Coverage) lands *after* the host card, the host card moves the Backups skeleton bars while they shimmer. The old shimmer is an `::after` translated −100 % inside an `overflow: hidden` bar. Chrome reported those pseudo-elements as moving from `(0,0,0×0)` to `y 587/613/639`, and scored the frame **0.149–0.151**.
- **Not timing luck:** holding Backups back 100–1,500 ms (a full 1.6 s shimmer cycle in 200 ms steps) gave **0.151 at every phase** with the old shimmer.
- **Why only sometimes:** all four calls use the same 2.5 s fixture delay, so whether Backups lands in the same frame as the host card depends on the runner. CI landed it later on both attempts (0.1572048824285957 both times). In the container it happened in 1 of 32 runs at 375 px before I held Backups back on purpose.
- **Not the font swap:** delaying the woff2 files 1.5 s moved nothing at 375 px (the `Geist Fallback` metrics match).

## Change

Web only, tokens only, no dependency, no API change. imp-124's behaviour is kept: Overdue names its slot and links to Open gaps.

- **`model.ts` / `coverage.tsx`, slot phrases:** `MissedSlot.slot` is now a list of phrases joined by spaces. `GapsLink` keeps each phrase whole (`whitespace-nowrap`), so a line breaks only between phrases, whatever the font:
  - same day: `["Missed Oct 22, 10:00–12:00 UTC"]`, never wraps;
  - cross day: `["Missed Oct 21, 23:00 –", "Oct 22, 01:00 UTC"]`, breaks after the dash;
  - off-page fallback: `["Missed a slot ending", "Oct 22, 12:00 UTC"]`.

  The text and accessible name are unchanged, and the old NBSP before "UTC" is no longer needed.
- **`sources-table.tsx`, note:** the fixed `md:w-45` is removed, so the slot sizes its column.
- **`sources-table.tsx`, cells:** 8 px between columns (`px-2`), 16 px at the table's outer edges (`first:pl-4` / `last:pr-4`, matching the panel header and the Coverage table). It was 12 px everywhere. This covers the header, the rows, the skeleton rows and the Planned rows.
- **`ui/skeleton.tsx` + `globals.css`, shimmer:** the sweep box is three bars wide (`-left-full w-[300%] -translate-x-1/3`). The gradient is transparent outside its middle third, and the keyframe moves it one bar (`translateX(33.333%)`). The sweep looks the same and is transform only. The box now always covers its bar, so it is never clipped to nothing. Reduced motion still ends on a static bar.
- **`summary-cards.tsx`, phone skeletons:** `CardSkeleton` takes per-fact bar heights below `sm`. The host card's Run now and Open gaps bars are 36 px (two lines), and the backups run-strip bar is 32 px, as their fixture values wrap at 375 px.
