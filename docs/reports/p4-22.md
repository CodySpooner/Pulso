## Behaviour

| Where | What |
|---|---|
| **Bell** | Top bar at every width. Its name says the exact count ("Alerts, 3 unread", "Alerts, none unread"); the badge caps at `99+`. With no API (every other e2e page) the bell shows no badge. |
| **Popover** | The latest 20 unarchived alerts, refetched on each open, grouped Today / Earlier by UTC day. Choosing a row marks it read and opens the product's Suppliers tab (`?tab=suppliers`), the test drawer, or the product. "Mark all read" keeps the menu open. "View all alerts" opens `/alerts`. The footer shows the last evaluation (flagged past 26 h). The popover has loading, empty, error with Retry, and stale states. |
| **`/alerts`** | Inbox and Archived (`?view=archived`) views, with `?type=` and `?unread=` in the URL. A dense table from md up, cards on a phone. Checkbox selection with bulk Mark read and Archive (Unarchive on Archived), and per-row Mark read and Archive / Unarchive with tooltips. Keyset Load more, 50 at a time. Rule status lines: "3 rules are on, 1 with no source yet. Last evaluation 8h ago." and "Testing: freight change: 1 evaluation skipped: data gap Oct 19 → Oct 21." Empty states: "No alerts yet" with Open Testing, "No alert matches these filters" with Clear filters, and "Nothing archived". Error and stale use the shared `PanelError` and `StaleLine`. No Rules tab yet (DEC-333 g). |
| **API** | `GET /v1/alerts?archived=true` (same keyset and filters). `POST /v1/alerts/unarchive {ids}` returns `{count}`. `read {ids}`, `archive` and `unarchive` are 404 `not_found`, with nothing changed, unless every id is the workspace's. |

**Click count, read an alert and open its product: 2.** One click on the bell, one on the row. The row click marks the alert read and navigates. The Playwright test `two clicks read an alert and open its product's Suppliers tab` asserts both.
