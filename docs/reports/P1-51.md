## What changed

Fix diff without P1-07c: 11 files, +308/−29. 232 of those lines are tests.

| P1-50 | Fix | Where |
|---|---|---|
| **H1** (E-18) | An import is not a sighting. It never clears `delisted_at` and never moves an existing listing's or variant's `last_seen_at`. Import text (listing title/handle/url/…, variant title/SKU/options) is written only to a new row, or when the import's `observed_for` is on or after the UTC day of the row's `last_seen_at`. New rows keep `first_seen_at = last_seen_at = captured_at`. The live path is unchanged. | `shopify_stores/records.py` (`refresh()`, `utc_day()`) |
| **M1** (E-17) | `Template.required_headers` is new, additive and empty by default. Shopify requires the `compare_at_price` and `available` headers, so a file without them fails in `parse_csv` before raw storage: a 422 with "Missing required columns: compare_at_price, available" in preview, and a failed run on commit. Blank cells: compare-at means no compare-at, available means unknown (documented in DEC-162, the template comment, `docs/DATA_SOURCES.md` and the vault note). CSV rows carry no `source_updated_at`. `variant_title` is passed only when present, like `sku`, so a blank or absent title keeps the stored one. | `imports/templates.py`, `imports/csv.py` (+1 line), `shopify_stores/imports.py` |
| **M2** | An import appends the listing snapshot only when its group lists every non-delisted variant the listing already has. Variant snapshots are written either way. | `records.py` |
| **M3** | `_store` rejects the import when `store.currency` is set and differs from the context currency, mirroring the `shop_id` check. Nothing is written. | `shopify_stores/imports.py` |
| **L2** | Live `parse()` rejects a null or missing variant `title`/`available` again. `Variant.title` defaults to `None` so imports can omit it. | `records.py` |
| **L3** | The `.js` panel orders by the latest listing snapshot from **live catalog captures** only. The new `LIVE_CATALOG` predicate is shared with `CATALOG_WRITER`. | `shopify_stores/__init__.py`, `variants.py` |
| **L4** | Rebased: both DEC tails kept (main through DEC-123, then DEC-152, then DEC-162). `apps/api/tests/test_admin.py::test_exact_import_cap_accepts_original_bytes` (imp-051, merged after the P1-07c base) committed Shopify JSON without the saved `shopify_import` context that P1-07c requires. The test now saves the context; production code is unchanged. | `apps/api/tests/test_admin.py` |
| **L1** | **Not done** (optional). One bad row URL still fails the whole file as `partial`/`ValueError` with no row errors. → imp-004 cleanup. | — |
