## Behaviour (DEC-336)

- **One filter object.** `GET /v1/screener?filters=<JSON Filters>&sort=&order=&cursor=&limit=` (limit 1–100, default 50). The same `Filters` model (`extra="forbid"`) validates the query and a saved screen, so a screen runs as stored. Bad JSON, an unknown key, NaN or an unknown stage gives `422 invalid_filters`.
- **Filters** (`<metric>_min` / `<metric>_max`, inclusive, AND). Every metric is in the units its row returns:
  - `margin_bps`: the caller's `workspace_product_economics` margin. Complete rows only (R-16).
  - `velocity`: Discover's V7, from `best_feature()`.
  - `acceleration`: G7(t) − G7(t−7), from the same family and feature version.
  - `saturation`: the latest Saturation row.
  - `price`: the lowest live USD store price, in minor units.
  - `supplier_rating`: hundredths of a star. The best live supplier listing's rating: its snapshot's, else the supplier's own.
  - `ship_days_us`: the fewest `max_days` among live supplier listings' US quotes at quantity 1, read from each listing's latest quoted day.
  - `lifecycle`: a set of stages.
  - `category`: an exact `category_id`.

  A product missing a filtered metric is out, because a NULL fails every SQL comparison. `risk_min` / `risk_max` are accepted, not applied, and named in `unapplied` with `"phase_5"`.
- **Sorts.** `trend` (default), `opportunity`, or any range metric; `desc` (default) or `asc`. Missing values come last in both orders, then the id in the sort's direction. The cursor is `[value | null, id]`. Opportunity is scored in Python with DEC-331's function over the whole filtered set: two batch `latest_rows()` reads and one economics read.
- **Rows.** Each row has every metric with its provenance:
  - `price_minor`, `supplier_rating` and `ship_days_us` are `Sourced` from the row the filter read.
  - `margin` is Discover's `margin_stat`; `velocity` is Discover's; `acceleration` carries the velocity's family, source and `as_of`.
  - `trend`, `saturation` and `lifecycle` are a lean `LatestScore` (value, stage, day, model_version, as_of, reason); full explanations stay on `/v1/products/{id}/scores`.
  - `opportunity` has value, as_of, confidence, reason and missing.
  - A missing metric is `{value: null, reason}`, never 0. Merged and emptied products never list.
- **Saved screens.**
  - `saved_screens`: `id`, `workspace_id`, `name` (1–80 characters, NUL-free, unique per workspace), `version` (1), `definition` (`{filters, sort, order}`, unset filters dropped), `created_at`.
  - `GET /v1/screens` lists by name with a keyset on the name; `POST` returns 201, or 409 for a used name; `GET /{id}`; `DELETE /{id}` returns the screen as it was.
  - Another workspace's screen is a 404.
