Source: the imp-127 report's leftover (`docs/reports/imp-127.md`). A never-run source's drawer says "Import a CSV from the CSV import panel to add its first run", but reaching the panel takes closing the drawer, scrolling and a click.

## Change

Two source files, both inside the brief's ownership:

- `apps/web/src/components/data-health/run-drawer.tsx`:
  - **The button.** In the never-run empty state, the words "CSV import panel" are now a link-styled `<button>`. It looks like the drawer's Open gaps link: border-strong underline, the trimmed down arrow (DEC-222 c), `link-inline`, and `me-1` before the Run-now variant's comma (DEC-222 b).
  - **When it shows.** Exactly where the copy already names the panel: `csv_import === "ready"` (imp-128), alone or after "Press Run now…". The text is unchanged, apart from a non-breaking space that keeps "first run." off a line of its own.
  - **The press** records the source key and closes the drawer. `onCloseAutoFocus` then calls the new `onImport(key)` prop instead of returning focus to the opener. That runs once the drawer has unmounted, the same point where the Open gaps link's focus moves.
  - **No empty exit.** `RunDrawer` keeps the last source it showed until the exit ends (imp-165's `useLastOpen` rule, written locally). This covers every close path, not only this button.
- `apps/web/src/components/data-health/data-health.tsx`: prop wiring only. `onImport={(key) => importPanel.current?.open(key)}` is the same call the Sources row's Import makes.

`open(key)` needed **no change**. `sources-table.tsx`, `model.ts`, `atoms.tsx`, `coverage.tsx` and `import-panel.tsx` are untouched. There is no API, schema, dependency or CI change.
