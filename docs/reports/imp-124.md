## Change

Frontend only, no API change, tokens only, no motion added.

- **`model.ts`:** `missedNote(key, latest_gap_ends, open_gaps)` returns `{ slot, reason }` for a source's latest missed slot. It merges the source's gaps on the loaded page (the existing `mergeGaps`) and picks the range ending at `latest_gap_ends[key]`: "Missed Oct 22, 10:00–12:00 UTC" with reason "Host offline". A cross-day range reads "Missed Oct 21, 23:00 – Oct 22, 01:00 UTC". When that gap isn't on the first gap page, it reads "Missed a slot ending Oct 22, 12:00 UTC" with no reason. The gap-reason labels moved here from `coverage.tsx` (`gapReasons`), so the note and the Open gaps table word a reason the same way.
- **`coverage.tsx`:** the Open gaps heading is the link target (`id="open-gaps"`, `tabIndex=-1`, scroll margin for the phone's sticky top bar). `GapsLink` renders the note as a link to `#open-gaps`: the slot on one line, the reason on the next, a down arrow, and the accessible name "Missed Oct 22, 10:00–12:00 UTC Host offline (in Open gaps)". A click or Enter focuses the heading, which scrolls only as far as needed (see **Found while building**).
- **`sources-table.tsx`:**
  - **imp-124:** the Overdue row's and card's status note shows the link. In the table it is a fixed 180 px, which keeps a same-day slot on one line and the table inside its region at 1440 px. It is never truncated. Under a coarse pointer the status cell gets 12 px vertical padding and the note 16 px above it, so the pill's and the link's 44 px hit squares stay apart and inside the row.
  - **imp-125:** the source name button is styled as a link at rest: underline in `--border-strong` (`currentColor` on hover) and a `ChevronRight` in `--muted-foreground`. It is the same button with the same accessible name ("Google Trends: open runs"), so nothing else changes.
- **`run-drawer.tsx`:** an Overdue drawer shows the same link under the title, in `--foreground` (6 px lower under a coarse pointer, for the same hit squares). Its click closes the drawer and focuses the Open gaps heading instead of the opener (`onCloseAutoFocus` checks a ref); if the heading isn't rendered, focus returns to the opener as before. Escape and the close button still return focus to the source name.
- Overdue precedence is unchanged (DEC-096, DEC-123): the note shows only when the state is Overdue, which needs the host's gap summary. When the host call is loading or failed there is no note, and after the rebase onto imp-133 those sources read Unknown (DEC-196).

## Found while building

- **Touch squares (fixed here):** the full chromium run first failed `touch-targets.spec.ts` at 768, 1024 and 1440: the Overdue cell grew to pill plus note, so the Overdue pill's 44 px square reached into the CJ row's Healthy pill above and into the note link below. The coarse-only spacing above fixes it with no change at a fine pointer.
- **Shell shift on a fragment jump (avoided here, cause pre-existing):** at lg the shell is `h-dvh` and scrolls inside `main`, but the document is still 1,319 px tall at 1440×900, because absolutely positioned boxes (sr-only text, an svg) escape the shell's `overflow-hidden` and extend it. A native jump to `#open-gaps` scrolled `main` to its end, then the document by 419 px, moving the top bar off screen until reload. The link now focuses the heading instead, which leaves the document at 0. The cause stays: any future in-page anchor or `scrollIntoView({ block: "start" | "center" })` near the page end can shift the shell. Proposed backlog row below.

## Leftovers and observations

1. **P3 — Open gaps hidden behind the coverage call.** The Open gaps list renders only when `GET /v1/admin/coverage` succeeds and is non-empty, although its data comes from the host call. With coverage failed or empty, the note link's target doesn't exist: the row link does nothing (focus stays on it), and the drawer link closes the drawer and returns focus to the opener. Proposed backlog row: *render Open gaps from the host call whatever the coverage state, so the gap list and the Overdue links survive a coverage failure* (vault [[UI States]]).
2. **P3 — the lg document is taller than the shell.** Escaped absolutely positioned boxes make the document scrollable behind the `h-dvh` shell (1,319 px at 1440×900), so in-page jumps can shift the whole shell (see above). Proposed backlog row: *contain the shell's absolute descendants (e.g. `overflow: clip` or a positioned `main` wrapper in `app-shell.tsx`) and assert the document doesn't scroll at lg*.
3. **Observation:** the host card's "latest Google Trends, Oct 22, 10:00 UTC" names the latest gap's start, while the note names its end (12:00) from `latest_gap_ends`. Both are right, and the note shows the whole range; worth a look if the host card is reworded.
