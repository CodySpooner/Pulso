## Cause

The lead's 17:05Z batch 2 (imp-090 + imp-094 + imp-080 + aud-013) turned two Playwright specs red at 375px (`.lead-imp080-batch2-failure-1711.txt`). imp-080 had rendered its focusable "Valid rows" scroll region between the counts (Import) and the "Row errors" region. A keyboard Tab from Import landed on the sample instead of the row errors, so:

- `import-announce.spec.ts:88`: Tab, Tab from Import reached Row errors, not **Retry**;
- `import-error-id.spec.ts:33`: Tab from Import reached the sample, not **Row errors**.

Placing the sample after the row errors alone would not have been enough. The commit's error line (Retry, Copy error ID) renders after the whole preview, so the sample would still have sat between Row errors and Retry.

## Change (focus order chosen)

`apps/web/src/components/data-health/import-panel.tsx`: `RowSample` moved out of `PreviewResult`. The panel now renders it last, after the row errors, the "Showing the first N of M errors" note and a failed import's `ErrorLine`. What needs acting on comes first in both reading and Tab order:

**Import → Row errors → Retry → Copy error ID → Valid rows sample**

- Both failing specs pass unchanged; neither was weakened.
- After a success the preview resets, so the sample and the outcome (Open runs) never show together.
- Programmatic focus is unchanged (DEC-145): Import keeps focus after a failed import, a Retry that fails again comes back focused, and Open runs takes focus after a success.
- imp-077/078 behaviour is unchanged: error-ID copy, transport recovery copy, and one announcement per step.
- imp-080 behaviour is unchanged: the bounded 20-row sample, the honest "first 20 of 1,284" heading, the accessible table, no live role, and no extra click.

Own specs updated to the new order, with no assertion removed:

- `e2e/data-health/import-rows.spec.ts`: Tab from Import now asserts Row errors first, then the sample (ring, End to the last row).
- `e2e/data-health/import-rows-screenshots.spec.ts`: Tab twice to reach the sample. A new failed-import shot shows the error line and Retry above the sample.

`docs/DECISIONS.md` DEC-174 **Decision** line: "between the counts and the row errors" becomes "last in the preview: after the counts, the row errors and a failed import's error line … (Import → Row errors → Retry → Copy error ID → sample)". The entry was never on `main`, so it is corrected in place rather than amended as DEC-174a.
