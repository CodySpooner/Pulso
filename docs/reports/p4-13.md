## Behaviour

**Star state (DEC-322 a).**
- `watched` means this workspace's "Main" holds the product, as DEC-314 b built; `watchlist_ids` lists every list holding it.
- One query per page whatever its size: a recursive CTE down `merged_into_id`, so an item of a product merged into the row's product counts (unstar removes it too).
- Workspace scoped. Discover's CSV export has no watch columns.

**Rows (b).** Each item's `product` is the product now, as Discover reads it. One merged after the add reads as its survivor, and the row shows a "Merged" pill with what was added.

**★ consistency (c).**
- A star flips `watched` in every cached read at once (product header, Discover pages, watchlist rows), keeping each query's fetch time, and rolls back on an error.
- The answer names Main, so `watchlist_ids` updates without a refetch.
- Removals, moves and list deletes refresh `/v1/watchlists*` and mark `/v1/products*` stale. Only queries on screen refetch.

**Undoable removal (d).**
- Hidden at once; the DELETE is sent after 5 s.
- Undo (the toast's button, or Ctrl+Z / ⌘Z) sends nothing, so `added_at` survives.
- A second removal, switching lists or leaving sends the pending one at once. Closing the tab inside the window keeps the item.

**The page (e).**
- A sub-nav of lists with counts (create, rename, delete with a confirmation naming the count). On a phone, a dropdown. The list is in `?list=`.
- A dense table: Product, Price, Velocity, Best margin, Stores, Added, Last seen. It uses Discover's cells, so each number opens its provenance card and missing ones read "No source yet".
- Row menu: Open product, Move to ▸, Remove. Bulk: select, Move to…, Remove, Clear selection.
- Cards below `md`. Rows fade out on removal; the lists aren't virtualized.
- States: loading skeleton, first visit, empty Main, empty custom list, error, refetch-failed StaleLine, per-row stale dot plus the word "stale", no source yet.

**Product Page (f).** A Watch / Watching toggle and a menu with every list, checked where the product is. The menu stays open, so several lists can change.

**Fewest clicks:**

| Flow | Clicks |
|---|---|
| Watch a product | **1** (★ on its Discover card or row, or Watch on its page) |
| See it | **1** (Watchlists in the nav; Main opens by default) |
| Move it | **3** (⋯, Move to, the list) |
| Remove it | **2** (⋯, Remove) |
| Undo | **1** (Undo), or Ctrl+Z |
